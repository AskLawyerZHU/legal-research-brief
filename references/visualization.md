# 可视化产出层

简报是「能引用的」，图是「能一眼看懂的」。**两者不能互相替代：图里不放来源标签，简报里不放结论没有的话。**

本文件管图。文字纪律见 `source-tagging.md`，结构见 `report-format.md`。

---

## 一、什么时候一定要出图

满足任意一条就出，不要等对方要：

| 触发条件 | 说明 |
|---|---|
| 主体 ≥ 3 方，且两两关系不同 | 三方以上的权利义务链，文字描述必然要来回翻 |
| 法律关系可分层（如劳动关系／经纪合约／竞业限制并存） | 分层正是图强于文字的地方 |
| 结论是「分布」而非「唯一答案」 | 判决金额、裁量区间、比例跨度，条形图比文字快 10 倍 |
| 争点之间有攻防方向（谁主张谁举证） | 箭头能表达文字很啰嗦的东西 |
| 交付对象是非法律专业 | 他看图的耐心远大于看条文 |

**不出的情况**：单一当事人、单一法条、结论唯一且确定。这种画图是浪费。

## 二、五种图型，按问题选

| 图型 | 回答什么问题 | 必修要素 |
|---|---|---|
| **法律关系图** | 谁对谁、什么关系、这个关系能不能成立 | 主体卡片（含各方举证重点）＋ 关系线（实线=成立／虚线=待证／红箭头=违约行为）＋ 每条关系的法律依据 |
| **请求权基础图** | 我要主张什么、缺哪个要件就断 | 请求 → 构成要件（并列）→ 每个要件的依据 → 缺失要件用醒目标记 |
| **结果分布图** | 同类事法院大概怎么判 | 横轴统一刻度、每案标「主张额／判决额」、**不可比的必须标不可比**、注明样本量 |
| **时间轴** | 哪些节点会改变权利状态 | 节点日期 + 该节点产生的法律效果；法定期间单独标色 |
| **争点攻防图** | 我方打哪里、对方会从哪里打回来 | 左右分栏（我方／对方）、每条主张挂依据、反例必须出现在图上 |

一份简报最多两张图。三张以上没人看。

**模板在哪**：法律关系图用 `assets/relation-map-template.html`；请求权基础图、结果分布图、时间轴、争点攻防图四种用 `assets/chart-templates.html`（四张图在同一文件里，各有独立 `<section>`，整段复制后替换 `{{}}` 占位符）。

> **不要凭记忆手写 SVG 骨架。** 第四节那七条硬约束（字号、内边距、连线不穿卡、标签不压线）就是手写最容易翻车的地方，模板里已经算好了坐标与行数。改内容可以，改坐标要重新核一遍宽度。

## 三、形态选择：为什么默认 SVG＋自包含 HTML

| 形态 | 适合 | 不适合 |
|---|---|---|
| **自包含 SVG＋内联 HTML** ✅ 默认 | 发给任何人、任何设备都能开；可打印、可截图为 PNG；文件小、不过期 | 不能在图形界面里直接拖拽改 |
| 设计工具画布（可编辑图层） | 自己还要继续改、需要图层级精修 | 对方没装就打不开，**不适合作为分享件** |
| 位图截图 | 贴进微信、贴进文档 | 放大就糊、无法改字、没法选中复制 |

**结论：给别人的一律 SVG＋HTML；给自己的可以另出可编辑稿。**两者内容必须一致，不要出现「我的版本和别人看到的版本不一样」。

## 四、布局硬约束（过不了这几条就别交付）

1. **正文字号 ≥ 12px，标题 ≥ 17px。**图是给人读的，不是给打印机省的。
2. **卡片内文字必须留内边距 ≥ 18px**，且**逐行核算宽度**：中文字宽≈字号，`可用宽度 ÷ 字号 = 单行字数上限`。宁可拆两行，不许溢出。
3. **连线不得穿过任何卡片。**画线前先算斜线在卡片四条边所在 y 值处的 x 坐标，确认落在卡外。算不清就把卡片挪开，不要赌。
4. **线上标签挂在线的上方或下方**，不要压线；标签宽度不得越过卡片边缘。
5. **不许用 emoji 做图形元素**（渲染环境不可控）；可用 ①②③④ 这类圈号。
6. **色彩只用语义色**：成立／有利、待证／酌减、不利／风险、中性。同一张图不超过四色。**色块不代表裁判对错**，图例里要写这句。
7. 打印时 `@media print` 去掉背景色与阴影，卡片 `break-inside: avoid`。

## 五、图里绝对不能做的事

- **不能把 `[待检索]` 藏起来。**图上必须有「待核验」区，写明哪几项没查到、怎么核。**图越漂亮，越容易让人忘记它还不完整。**
- **不能在图里给无来源的结论。**「法院一般认为」这种话，文字里不许写，图上更不许放大字号写。
- **不能用图做过度归纳。**四个样本画成条形图，看起来就像统计；必须同时标注「样本量 4，不足以支撑『多数法院认为』」。
- **不能省略永久标识。**主体和结论上可以直接写案号／条款号，成本很低，收益是图被转出去后还能回溯。
- **不能用视觉比例夸大差异。**横轴必须从 0 起，等距刻度；不许截断坐标轴制造视觉冲击。

## 六、交付前自检

- [ ] 图里每个数字都能在简报正文找到出处
- [ ] 图里的结论没有超出简报结论（图不能比文字更敢说）
- [ ] 渲染后逐项检查：文字无溢出、连线不穿卡、标签不压线
- [ ] 待核验区存在且非空（若确实全部核验完毕，写「本次无待核验项」）
- [ ] 打印预览一页放得下；放不下就拆图，不要缩字号
- [ ] 色块有图例，图例说明「不代表裁判对错」
- [ ] 样本量已标注
