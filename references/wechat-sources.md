# 法院发布与公众号文章（第四轨）

条文和案例是「有编号的」，法院发布和公众号文章是「有观点但没编号的」。后者补的是**裁判思路、说理过程、口径变化**——这些在判决书摘要里看不到，在检索库里也搜不出来。

**但它不能当法条用，也不能当判例用。** 引用纪律比前两轨更严。

---

## 一、先纠正一个常见误解：官网比公众号更原始

大多数法院公众号的文章，是从自家官网/内网发布的稿子二次分发的。**同一个案子，官网版本更全、更少删改、标题不被编辑动过。**

所以检索顺序是：**法院官网 → 法院公众号 → 人民法院报等专业媒体 → 聚合转载（尽量不引）**。

常用一手入口（检索时按辖区加）：

| 机构 | 官网域名特征 | 说明 |
|---|---|---|
| 最高人民法院 | `court.gov.cn` | 指导性案例、司法解释、司法政策原文 |
| 上海一中院 | `a-court.gov.cn` | 裁判观点栏目质量高，常发「衡石·观点」类长文 |
| 山东高法 | `sdcourt.gov.cn` | 辖区各中院典型案例集中挂载 |
| 各省高院 | `{省简称}court.gov.cn` | 如 `hunancourt.gov.cn`（湖南） |
| 各中院/基层院 | `{市}{区}fy.{省}court.gov.cn` | 如 `cdzy.hunancourt.gov.cn`（常德中院） |
| 人民法院报 | `rmfyb.chinacourt.org` | 案例报道的原始出处，常被各大媒体转载 |

公众号原文链接特征：`mp.weixin.qq.com/s?__biz=…&mid=…&idx=…&sn=…`
——**看到 `__biz` 参数才是公众号原文**，没有这个参数的都不是。

## 二、源的可信度分三级

| 级别 | 典型来源 | 能怎么用 |
|---|---|---|
| **一手** | 法院官网、法院认证公众号、人民法院报 | 可作「裁判思路」依据引用，须标机构与日期 |
| **二手** | 法治日报、检察日报、省级政法委号 | 可作线索，引用前回溯一手源 |
| **三手** | 腾讯新闻／网易／澎湃号／今日头条等聚合转载 | **只作线索，不作依据**；标题常被改写、正文常被删节 |

### 转载污染：必须防，而且要主动防

聚合站为了流量会改标题、加编者按、掐掉法官说法的后半段。**同一篇文章，转载版和原文版可能读起来是两个意思。**

实测例（2026-11 检索）：山东高法发布的一起「劳动者使用化名入职是否构成欺诈」案，
一手源标题是**案件事实型**，到了聚合站变成「员工嫌父母起的名字不好听，一直使用化名上班……」——
情绪化改写，把法院的裁判要点（欺诈三要件）挤到了文末。

**规则**：

1. 搜到转载 → 先用文末「来源：XX法院」或文中案号／案由回溯一手源，找到原文再引用。
2. **不得把转载标题当原文标题引用**。
3. 转载正文与官网正文冲突时，以官网为准，并在简报中注明存在版本差异。
4. 转载稿里没有法官姓名、没有发布日期、没有原文链接的，一律降为 `[待检索]`。

## 三、检索式怎么写

### 首选方案：把检索范围直接限定在公众号域名内（实测可用，无需登录）

**这是本能力的主路径**：搜索时把结果域名限定为 `mp.weixin.qq.com`，返回的就**只有公众号文章**，正文全文、原始直链、发布号名一并带出，不需要登录、不需要知道标题。

| 参数 | 怎么设 |
|---|---|
| 域名限定 | `allowed_domains: ["mp.weixin.qq.com"]` |
| 关键词 | 就写主题词本身，**不要**再加「公众号」二字（已经限定域名，加了反而缩小召回） |
| 时间窗 | `freshness`：`d1`／`d7`／`d30`／`y1`；**做法治动态、早间速览必须加** |

**实测记录（2026-11-15，三次不同主题均为纯关键词，事先不知道任何标题）**：

| 主题 | 结果 |
|---|---|
| `主播竞业限制 违约金` | 5 篇，含省高院审监庭课题组长文、含 （2020）沪01民终13707号 的违约金实证分析 |
| `竞业限制 违约金` ＋ `d30` | 5 篇，含（2026）渝民申300号、指导案例 184／190 号、人社部《企业实施竞业限制合规指引》第 14 条的解读 |
| `企业简易注销 债权人 债务承担 股东责任` | 5 篇，含 (2025)粤2071民初2912号、公司法第 240 条与公司法解释（二）第 20 条的适用对比 |

**它能做到**：按主题找文章、抓全文、拿到文中的案号与法条、限定时间窗。
**它做不到**：某个号的历史全量、按公众号名穷举、按阅读量排序。要这些得走下一节的备用路径或第四节的能力边界。

### 第二条通道：搜狗微信（配合脚本可自动化，已实测）

`https://weixin.sogou.com/weixin?type=2&query={关键词}&page={N}` 返回结果列表，带**公众号名＋发布日期＋摘要**。

**⚠️ 更正前一版结论**：早前本文写「连续两次即被验证码拦、不可自动化」，那是**裸请求**（单次 WebFetch、固定 UA、无 cookie）的实测结果，不是通道本身的上限。加上下面两步即可稳定连续请求：

1. **先取 cookie**：请求 `https://v.sogou.com/v?ie=utf8&query=&p=40030600`，从 `set-cookie` 里提取 `SNUID` 等，后续请求带上。
2. **UA 轮换**：备一组桌面＋移动 UA 随机取，别用固定 UA。

实测（2026-11-15，同一 IP 连续三次不同关键词）三次全部正常返回，无验证码：`竞业限制 主播`、`上海一中院 竞业限制`、`山东高法 竞业限制`。后者 5 条中有 2 条是「山东高法」官方号原文。

**仍然存在的限制**：
- 搜索结果里的 `weixin.sogou.com/link?url=...` 是**中转链接**，脚本尝试解析真实 `mp.weixin.qq.com` 地址**实测成功率为 0**（3/3 失败）。只能给中转链接，需在浏览器打开。**要引用就给「标题＋公众号＋日期」，链接仅作辅助。**
- 每页 10 条，翻页有上限；密集请求仍可能触发频控，批量跑要加延时。

**执行方式：可选增强脚本（默认不装，先问）**

主路径（域名限定检索）零依赖、必跑；下面这个脚本只是**增强**，不是前置条件。按「探测 → 询问 → 代办安装 → 验证 → 降级」五步走：

1. **探测**：查 `~/.workbuddy/skills/wechat-article-search/scripts/search_wechat.js` 是否存在。存在就直接用，跳过安装。
2. **询问**（一句话，说清代价与替代，不诱导）：
   > 公众号检索可以增强：装一个几百 KB 的开源小工具，一次搜出带公众号名和发布日期的清单。纯搜索用，不上传你的任何数据。要装吗？不装也能用，只是结果少一些、日期要你自己核对。
3. **同意后代办**（GitHub 直连多不通，走镜像；路径用 `~`，不写死用户名，换人可用）：

5. **降级**（用户不同意或装不上）：走下面两条替代路径之一，并在简报「检索范围」注明「本次未启用增强通道」。

**替代路径 A（零依赖，首选）**：域名限定检索——检索时限定 `mp.weixin.qq.com`，只写主题词，按需加时间窗（见本节「首选方案」）。

**替代路径 B（有代码能力时）**：按上文「第二条通道」的两步原理（先取 cookie、UA 轮换）自行请求并解析 `ul.news-list`，一次性实现，**不随本技能包分发**。

### 检索式写法（在上述通道内使用）

| 目标 | 检索式写法 | 备注 |
|---|---|---|
| 某法院对某问题的观点 | `{法院名} {核心法律术语} 裁判观点` | 术语要用规范表述，不用生活词 |
| 某法院的典型案例 | `{法院名} 典型案例 {案由}` | 加「典型案例」比加「案例」准 |
| 找公众号原文 | `{主题词} 公众号` 或 `{号名} {主题词}` | 命中 `mp.weixin.qq.com` 即原文 |
| 只看最近发布 | 加时间过滤（近 1／3／7／30 天） | **做法治动态、早间速览必须加**，否则混进旧文 |

**检索式要写进简报**，让人能复现。

### 纠偏不能靠删词：两组并行，取并集

> **先看这条边界**：本节讨论的是「通道已经对了、但召回偏了」时怎么调词。**如果整类文章都搜不到，先怀疑通道，不要先改词**——把泛检偏移归因于检索词，会一路走偏（下面的三轮就是实例）。

实测教训（2026-11-15，主播竞业限制主题）：

| 轮次 | 做法 | 结果 |
|---|---|---|
| 第 1 轮 | 用主题词「主播 竞业限制」泛检 | 召回几乎全是**经纪合同违约金**案，真正的竞业限制纠纷没露面 |
| 第 2 轮 | **把「竞业限制」整个删掉**，改打「劳动关系认定 从属性」 | 矫枉过正——定性类文章拿到了，但上海一中院、上海二中院两篇**最贴题**的竞业限制专文被漏掉 |
| 第 3 轮 | 保留主题词，改成**按号名定向检索** | 两篇全覆盖 |

**规则**：主题词召回太泛时，正确做法是**并行保留两组检索式**，不要用一组替换另一组：

- **定性组**：`{主体} 劳动关系 从属性 认定`
- **主题组**：`{主体} {本主题法律术语} 适格主体`（术语用规范表述，如「竞业限制」而非「竞业禁止／不许跳槽」）

两组都跑、结果取并集。**删掉一组等于自断一臂**——尤其当主题词本身是专业术语时，它恰恰是命中最精确文章的钥匙。

### 三个提高命中的写法

1. **按号名打，别只按主题打**。已知目标法院时用 `{法院名} {主题}`，比泛搜精准得多。这也是「订阅特定号」在严肃检索里不可替代的原因。
2. **把「白皮书」当关键词**。白皮书往往附带最精选的案例且成体系，是单篇文章无法替代的载体。同理可用「审判白皮书」「典型案例」「年度案例」「参考案例」。
3. **加 `典型案例` 比加 `案例` 准**；**加「裁判观点」「案例分析」「法官说法」能筛掉新闻稿**。

### 回测记录：修正后能否复现人工检索成果（2026-11-15）

拿同一主题（主播竞业限制）做回测，目标是**把用户人工找到的两篇公众号原文找回来**。结论：能，但两篇难度不同，说明必须多写法并行。

| 目标文章 | 实际命中路径 | 结论 |
|---|---|---|
| 上海二中院《网络主播是否属于竞业限制义务适格主体？》（至正·案例分析） | `上海二中院 网络主播 竞业限制义务 适格主体` — **第 1 条即公众号原文** | 主题组一次命中 |
| 上海一中院《避免竞业限制「一刀切」，法院为主播用工规范亮明规则》 | 用「白皮书」那轮**只出转载**（新华网／工人日报／千龙网／律师网）；改用 **引号精确标题 ＋「公众号」** 才在第 1 条浮出 `mp.weixin.qq.com` 原文 | 需精确标题锁定 |

**由此补两条**：
4. **加引号锁标题**。当已知标题（或从转载稿里读到了原标题），用 `"原标题关键词" ＋ 号名/公众号` 检索，能越过大量转载稿直取原文。转载稿越多，这一步越必要——搜索引擎会把高权重新闻站排在前面。
5. **长链可能被风控，短链更稳**。`mp.weixin.qq.com/s?__biz=...&sn=...` 这种参数长链在部分环境下返回「环境异常，请完成验证」；`mp.weixin.qq.com/s/{短id}` 通常可直接读。**两者指向同一篇**，抓不到时换形式重试，不要据此判定文章不存在。

**附带收获（这条比回测本身更有价值）**：同批次还检出一篇**比目标文章更新**的稿件——上海一中院 2026-11-11《全文发布！新就业形态劳动权益保护典型案例》六件，其中案例六即此前只找到转载版的「在校大学生直播勤工助学不构成劳动关系」案，这次拿到了官方全文。

> **口径**：定向回捞已知文章是「验证题」，不是「检索题」。真做检索时不要预设答案存在——否则会为了凑齐而把似是而非的转载当原文。**回测通过 ≠ 下次不会漏。**

### 关键回测二：号名 ＋ 主题 ＋ 域名限定，直接打穿官方号（2026-11-15）

上面那次回测是「已知标题」，只能证明命名的价值。**真正该验的是：不知道任何标题，只知道法院名和主题，能不能拿到该号自己的文章。**

| 查询（均为域名限定 ＋ 纯关键词，不知道任何标题） | 结果 |
|---|---|
| `上海一中院 竞业限制 白皮书` | 第 1、2 条均为**上海一中院官方号**（`__biz=MjM5MjkwMDkxMA==`）原文：《上海一中院竞业限制纠纷案件审判白皮书》全文、《现场直击｜上海法院首份竞业限制纠纷案件审判白皮书》，含 2015.1–2018.3 受理 48 件／审结 47 件的数据与五件典型案例 |
| `山东高法 竞业限制` | 命中「鲁法案例」原文、山东省 2024 年度劳动人事争议十大典型案例第 5 件（任某阀门公司案）、鲁法案例【2022】116号 |

**结论：`号名 ＋ 主题 ＋ 域名限定` 是查「某法院自己怎么说」的最短路径**，比泛检准得多，且能直接拿到号内长文（白皮书、典型案例汇编），这些在新闻转载里往往被删节。

**注意**：号名要写该号对外自称的名字（`上海一中院`、`山东高法`），不是全称（`上海市第一中级人民法院`）。全称反而召回差。

## 四、引用格式

```
《{文章标题}》｜{发布机构}｜{YYYY-MM-DD}
原文：{一手源链接}
〔如引的是转载〕转载自 {转载站}，原文见上；转载标题与原题不一致时以原题为准
〔如无法回溯一手源〕[待检索] 仅见转载，未能核实原文
```

三条硬要求：

1. **必须有发布机构 + 发布日期**。公众号文章没有这两项，等于没有出处。
2. **必须区分「法院说的」和「作者说的」**。法院公众号里的「法官说法」「典型案例」是职务表达；「衡石·观点」「调研」类栏目是个人观点，署名到人。**两者引用价值不同，不得混为一谈。**
3. **不得用公众号文章代替判决书**。文章是解读，判决书是依据。要引裁判结论，回案例库拿案号。

## 五、不能做的事

- **不能说「某号文章已全部检索」**。搜索引擎是相关性排序，不是订阅，必然漏。
- **不能用一篇公众号文章概括「某法院的裁判口径」**。一个案子是一个案子。
- **不能把公众号文章写进「法条索引」或「类案要旨」两节**——它只能进「参考观点」或单列的「法院发布」节。
- **不能省略转载声明**，让人以为你读的是原文。
- **不能引用没有署名的「据某法院」类文章**。

## 六、要「不漏」怎么办（能力边界，如实告知）

**先说定位，免得做偏**：这条轨是「**做检索那一刻**多跑的一条并行通道」，和法条轨、案例轨并排。**不是**订阅跟踪系统——不需要定时任务、不需要 RSS、不需要配置任何接口。一次检索多跑两个查询就够。

域内检索解决了「按主题找文章」，但解决不了「某号发的每一篇都要」。

| 需求 | 可行做法 | 代价 |
|---|---|---|
| 按主题找文章 | **域名限定检索**（第三节首选方案） | 零成本、无需登录、可加时间窗；但不保证全 |
| 只查某个法院号怎么说 | **号名放最前 ＋ 主题 ＋ 域名限定**（如 `上海一中院 竞业限制 白皮书`、`山东高法 竞业限制`） | 实测直接命中该号官方原文，见第三节回测 |

| 一次性确认「某文是哪个号、哪天发」 | 搜狗微信（第三节备用方案），人工单次查 | 连续请求即被验证码拦，不可自动化 |

**对使用者要讲清楚**：这条轨给的是「线索和思路」，不是「穷尽的证据」。对外交付时，观点类内容一律标注为参考，不替代条文与判例。
