# 来源标签与双层引用

## 一、标签只有五种，不许自创

| 标签 | 什么时候用 | 能不能进结论 |
|---|---|---|
| `[库名·已验证 YYYY-MM-DD]` | 本次实际检索返回，且已核对条目完整（条号/案号、时效、来源） | ✅ 可以 |
| `[库名]` | 实际返回，但未做二次核对 | ✅ 可以，需注明未复核 |
| `[口径分歧]` | 两个来源说法不同，已并列 | ✅ 可以，须两种都写 |
| `[待检索]` | 没检索到，只给了检索式 | ❌ 只进清单 |
| `[模型知识·不可引用]` | 模型记忆，无库可验 | ❌ 禁止写进任何结论 |

`库名` 写实际来源：`元典`／`法宝`／`国家法律法规数据库`（人工核对时）。

> 没有"大概""应该是""据了解"这类无源表述。写不出标签，就说明这条不该出现在正文里。

## 二、引用格式

### 法条

```
《中华人民共和国民法典》第五百零九条
【原文】当事人应当按照约定全面履行自己的义务。……
【时效】现行有效｜法律｜2020-05-28 通过，2021-01-01 施行
【来源】元典法规库｜检索日期 2026-11-14
【链接】https://…（实测多为需登录；如为免登录须写「有效期至 YYYY-MM-DD」）
```

四个字段一个都不能少：**原文、时效、来源、检索日期**。效力级别能取到就写。

### 案例

```
（2025）辽04民终XXX号｜抚顺市中级人民法院｜二审｜2025-XX-XX
【案由】合同纠纷
【裁判要旨】……（用自己的话概括，标"要旨"而非原文引用时须说明）
【相关性】高｜理由：案由、法律关系、争议焦点一致
【效力】普通案例（非指导性/公报案例）
【来源】元典案例库｜检索日期 2026-11-14
```

案号、法院、日期三者必须齐全。缺一项 → 降为 `[待检索]`，不进正文。

### 地方文件／会议纪要

额外标注 **适用范围**（如"辽宁省内参考""仅限商事审判"），并说明其非正式法源地位。

## 三、双层引用（必须成对出现）

| 层 | 内容 | 特性 |
|---|---|---|
| **永久层** | 法规全名＋条款号 / 案号＋法院＋裁判日期＋来源库＋检索日期 | 不会失效，可凭文字在任何官方库复核 |
| **临时层** | 可点链接（**仅当 `share_access = login_free` 时给出**） | **计时失效**，必须注明到期日 |

规则：

1. 永久层**永远不能省**。链接失效后，它是唯一的复核路径。
2. 临时层只在 `share_access = login_free` 时提供；`login_required` 就不给链接。
3. **实测常态是 `login_required`**（元典本机账号层级，普通库与权威库均如此），因此**多数情况下报告里根本不存在临时层**——这不是缺陷，是必须如实呈现的事实，不要为了「看起来完善」硬造链接。
4. 需要把原文转交客户或非同行时，**靠全文摘录，不靠链接**：把 `court_reasoning`、`judgment_result` 原文摘进报告并标出处，不写「详见链接」。
5. 报告末尾统一声明：「文中如附链接，为检索时生成的限时链接；如已失效或需登录，请按永久标识在官方数据库复核。」
6. 不要把免登录链接当长期引用缓存或转发。

## 四、时效标注

- 默认只检「现行有效」；写报告时注明这是默认筛选的结果。
- 引用失效／被修改条文时，必须同时给现行版本，格式：

```
⚠️ 该条已于 YYYY-MM-DD 失效／被修改
现行规定：《新法规名》第 X 条 ——（原文）
```

- 做沿革比较时才主动检索历史版本，并用 `reference_date` 取指定日期有效版本。

## 五、分歧标注

两个来源（两库、两审级、两地区）结论不一致时：

```
[口径分歧]
A｜来源：X 库，（2024）…号｜观点：……
B｜来源：Y 库，（2025）…号｜观点：……
差异原因（推测需标明是推测）：审级不同／地域裁判习惯／时间跨度
```

**禁止**取平均、禁止择一隐去另一条、禁止合成一句"多数观点认为"（除非真做过数量统计并说明样本）。

## 六、报告末尾的检索声明（模板）

```markdown
## 检索范围与说明
- 检索日期：2026-11-14
- 数据来源：元典法规库／元典案例库（普通库 + 权威库）
- 时间范围：案例 2023-01-01 至 2026-11-14
- 地域范围：全国（重点辽宁省）
- 审级：一审至再审
- 未覆盖：地方规范性文件仅检索到 X 件；案例库最多返回前 500 条，命中数超出时已按相关性截取
- 局限：本简报为检索底稿，不构成法律意见；引用条文请以官方发布文本为准
```

## 七、正反例

| ❌ 错 | ✅ 对 |
|---|---|
| 根据《民法典》相关规定… | 根据《民法典》第五百零九条（现行有效）… |
| 司法实践普遍认为… | 检索到 3 件同类案例支持（其中 1 件为二审），另有 1 件相反（见附录 B） |
| 类似案例（2023）民终XXX号 | （2023）辽01民终1234号｜沈阳市中级人民法院｜2023-06-15 |
| 该规定仍然有效 | 该规定现行有效（元典，检索日期 2026-11-14） |
| 详见链接 | 永久标识：…；链接：…（免登录，有效期至 YYYY-MM-DD）／（需登录，已摘录原文于上） |
