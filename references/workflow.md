# 工作方法 · 争点拆解与交叉复核

## 一、把口语问题变成法律问题

对方说「他不给钱怎么办」，先问三件事，缺一件就补问：

1. **谁向谁主张什么**（主体 + 请求内容 + 金额/标的）
2. **依据什么法律关系**（合同／侵权／身份关系／物权／劳动……）
3. **卡在哪一步**（有没有约定？履行到哪？对方以什么理由拒绝？）

三问答不上来，检索一定跑偏。这一层不收费，但最省时间。

## 二、按请求权基础拆，不按关键词拆

```
请求（要什么）
 └─ 请求权基础（哪条规范支持）
     └─ 构成要件（每条规范拆 2–5 个）
         ├─ 要件一 → 争点 → 检索点
         ├─ 要件二 → 争点 → 检索点
         └─ 抗辩事由 → 争点 → 检索点（必查）
```

**抗辩必须单列一行**：只检索支持己方的规范，等于只做了一半检索。

示例（教育基金给付）：

| 要件 | 争点 | 检索点 |
|---|---|---|
| 协议有效 | 离婚协议中的给付条款是否有效 | 民法典合同编 + 婚姻家庭编解释 |
| 给付条件成就 | 「年满十八周岁」是否为唯一条件 | 条文原词 + 类案中对"附加条件"的解释 |
| 义务人未履行 | 拒付是否有正当理由 | 抗辩事由类案（经济困难、分期主张） |
| 违约责任 | 逾期利息标准 | 类案中 LPR 适用口径 |
| 主体资格 | 签约一方能否单独起诉 | **对立案例必查**（对方最可能的抗辩） |

## 三、检索点分类（每类都要覆盖）

| 类型 | 作用 | 缺了会怎样 |
|---|---|---|
| 法律条文 | 请求权基础 | 没有大前提 |
| 司法解释／会议纪要 | 细化适用标准 | 结论悬空 |
| 指导性／公报案例 | 定调 | 不知道上级法院口径 |
| 普通类案（本地） | 预判 | 脱离本地实践 |
| **对立案例** | 找对方弹药 | 庭审被打个措手不及 |
| 学理（可选） | 解释争议条款 | 说理单薄 |

## 四、关键词设计

优先级：**法条原词 > 司法解释用语 > 生活化描述**。

- 先用条文里的规范用语检索，再用生活词兜底。
- 同义词组要成对准备：如「违约金过高／酌减／调整」「竞业限制／竞业禁止」。
- 加限缩词提高精度：案由 + 法院层级 + 年份 + 「本院认为」段落关键词。
- 案例检索里，`分析过程关键词`（说理段）比全文关键词精准得多——争议焦点通常只在说理段出现。

## 五、类案相关性：只分三档，不打分

不计算相似度百分比（分母不可知，算了也是假的），只做三档判断，并在报告里写明理由：

| 档 | 判断标准 |
|---|---|
| **高** | 案由相同 + 法律关系相同 + 争议焦点重合 + 关键事实（如"约定成年给付"）同类 |
| **中** | 案由或法律关系有一项不同，但争议焦点与说理可迁移 |
| **低** | 仅关键词命中，说理逻辑不可迁移（**不进正文，只进附录**） |

同时必须标：审级、裁判日期、是否权威案例。**二审／再审改判的，要写清改判理由**，不能只引结果。

## 六、交叉复核

对进入结论的 3–5 条关键依据，各做一次独立重检，选以下任一方式（不同依据用不同方式更有效）：

1. **换表述**：把"违约金过高"换成"违约金酌减"，看结论是否稳定。
2. **换库／换字段**：法条检索换语义检索；案例检索改用援引法条反查。
3. **反向查**：拿案号反查它援引了哪些法条，核对是否与你的引用一致。
4. **跨源对照**：同一问题用两套技能或两个库各跑一次（有条件时），刻意找分歧。

结果三态：

| 结果 | 标注 | 处理 |
|---|---|---|
| 一致 | `已复核` | 正常写入结论 |
| 不一致 | `口径分歧` | 两种说法并列 + 各自来源与时间，**不合并** |
| 查不到 | `未复核` | 结论降级为"倾向"，并写明缺什么 |

### 检不到条文时的降级顺序（实测补充）

按法规名检索**条文级**内容可能返回空——部分司法解释在库中只有法规级条目、没有条文级索引（实测：《劳动争议司法解释（一）》法释〔2020〕26号，按全名与「若干」两种写法各试一次均无结果，但其条文常被判决援引）。

遇到这种情况按序走，不要跳步猜条文：

1. 按法规全名查 `search_articles(regulation_name=...)`；
2. 换关键词＋`primary_effect_level`（如 `司法解释`）筛选，不带法规名；
3. 用 `search_regulations` 查该法规是否存在、文号是否对得上；
4. 仍检不到 → 标 `[待检索]` 并写明「本库按 X 种方式检索未检得原文」，给出人工核验路径（法规文号＋官方库）；
5. **绝不**因为"这条我大概记得"就写进正文。被判例援引 ≠ 条文已核实。

同理反向：判决书里引用的规则可能有三种状态——条文仍有效、已被新解释吸收、已被实质改写。**引用前必须查现行有效性，不能照抄判决书的表述。**

## 七、什么时候算检索够了

满足以下三条即可停，不必无限扩大：

1. 每个要件至少有一条规范依据 + 一条类案支撑；
2. 抗辩事由有对应检索结果（哪怕是"未检索到相反判例"，也要写明）；
3. 关键依据做过一次复核。

达不到就如实说"某要件缺类案支撑"，而不是用更多低相关案例把篇幅填满。

## 八、常见错误

| 错误 | 后果 |
|---|---|
| 用生活词直接检索，不做术语转换 | 召回一堆无关结果 |
| 只查指导性案例，不看本地类案 | 结论脱离实际裁判习惯 |
| 只找支持己方的判例 | 庭审被反例击穿 |
| 把"未检索到"写成"不存在" | 虚假确定性，最危险 |
| 用一篇类案的结论概括"司法实践" | 过度归纳 |
| 检索式不记录 | 无法复现，无法复核 |
